# Video Editing Bot

A simple and powerful Python automation tool that:
- Speeds up videos by 1.20x
- Enhances color (temperature, tint, saturation)
- Keeps original audio
- Saves all edited videos to a new folder

## How to Use

1. Put videos in the input_videos folder
2. Run python main.py
3. Edited videos appear in output_videos

## Tools Used
- Python
- FFmpeg
